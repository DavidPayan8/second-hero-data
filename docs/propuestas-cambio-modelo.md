# Propuestas de cambio al modelo

Cuando algo al implementar no encaja con `docs/modelo/` (un campo que el proveedor no da, una restricción que no se puede cumplir, un hueco), se apunta aquí **en vez de cambiar el esquema por cuenta propia**. David lo lleva a la conversación de diseño; cuando se decide, se actualiza el doc del modelo correspondiente y se marca aquí como resuelto.
